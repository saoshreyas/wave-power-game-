# Wave Power Dive

A two-player browser game for elementary students that shows why an
underwater docking station powered by a wave energy converter (WEC)
helps autonomous underwater vehicles (AUVs) survey more ocean.

Made by the WA Wave Outreach Team.

## How to play

- Two players share one keyboard. Survey (color) as many ocean squares as you can.
- **Surface Sub:** when its battery dies, it floats up and waits for the
  charging ship to sail out (at least 15 seconds).
- **Dock Sub:** charges any time at the wave-powered dock in the middle.
- Controls: W A S D for one sub, arrow keys for the other. Rematch swaps subs.
- M mutes sound. I opens the "About" screen for teachers.

## Run it

Open `index.html` in any modern browser. No install or internet needed.

## Play online with GitHub Pages

Settings > Pages > Deploy from a branch > `main` / root.
